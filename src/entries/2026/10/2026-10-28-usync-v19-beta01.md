**Repo:** [KevinJump/uSync](https://github.com/KevinJump/uSync)

- Released uSync [`v19.0.0-beta01`](https://github.com/KevinJump/uSync/releases/tag/v19.0.0-beta01) for Umbraco 19.0.0-beta1 on .NET 11, on [NuGet](https://www.nuget.org/packages/uSync/19.0.0-beta01) and npm as [`@jumoo/usync`](https://www.npmjs.com/package/@jumoo/usync) (`next-19`)
- v19: ported to Umbraco 19.0.0-beta1 and net11.0, with cookie auth for SignalR and the uSync API
- v19: uSync opens in its own Synchronisation section by default, Admins get the section on first boot
- v19: copying a legacy folder can migrate Multi Node Tree Pickers, single media pickers and single dropdowns to the new v19 editors
- v19: pre-v19 data type config imports the way Umbraco 19 migrates it, plus mappers for the new picker editors
- v19: imports run as the requesting or background user, content is saved as the file's writer or the importing user
- v19: segment values sync as culture overrides, schedules keep their invariant-for-variant flag, library elements in blocks count as dependencies, blueprint move and folder fixes
- v19: removed everything marked obsolete for v18 and v19
- v17/v18: member type compositions import, blueprint folder names keep their spaces
- Released uSync [`v17.5.1`](https://github.com/KevinJump/uSync/releases/tag/v17.5.1)
- All branches: PRs get labelled with the release they'll ship in
