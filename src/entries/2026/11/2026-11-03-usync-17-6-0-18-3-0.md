**Repo:** [KevinJump/uSync](https://github.com/KevinJump/uSync)

- Released [`uSync 17.6.0`](https://www.nuget.org/packages/uSync/17.6.0) to NuGet, with the [v17.6.0 GitHub release](https://github.com/KevinJump/uSync/releases/tag/v17.6.0)
- Released [`uSync 18.3.0`](https://www.nuget.org/packages/uSync/18.3.0) to NuGet, with the [v18.3.0 GitHub release](https://github.com/KevinJump/uSync/releases/tag/v18.3.0)
- Both: the change details dialog previews items with the real backoffice editors, current and incoming side by side with the differences highlighted. Covers data types, document/media/member types, content and media, via a dry run of the serializer ([#1166](https://github.com/KevinJump/uSync/pull/1166), [#1168](https://github.com/KevinJump/uSync/pull/1168))
- Both: previewing an item whose doctype isn't on the site yet returns a failed preview instead of a 500 ([#1189](https://github.com/KevinJump/uSync/pull/1189))
- Both: [`@jumoo/usync`](https://www.npmjs.com/package/@jumoo/usync) published to npm, 18.3.0 as `latest`, 17.6.0 as `latest-17`
- v18: CHANGELOG.md gets 18.3.0 and the missing 18.2.1 entry ([#1191](https://github.com/KevinJump/uSync/pull/1191))
